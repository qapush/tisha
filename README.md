# 💩 Карта Тиши

Веб-приложение: закидываешь фото → оно читает координаты из EXIF → ставит метку на карте.
Карта и список публичные, загрузка и удаление — под паролем.

**Стек:** Next.js 15 (App Router) · Neon (Postgres) · Cloudflare R2 (фото) · Leaflet + OpenStreetMap · Vercel

---

## Как это устроено

Фотографии никогда не проходят через сервер. Браузер:

1. читает EXIF из **оригинала** (`exifr` умеет и HEIC, конвертация не нужна);
2. если файл HEIC — декодирует его через `heic-to` (libheif в wasm, подгружается только при
   необходимости);
3. ужимает до 1600px WebP + миниатюру 400px (~150 КБ и ~15 КБ);
4. запрашивает у `/api/admin/upload-url` две подписанные ссылки и **грузит прямо в R2**;
5. отправляет в `/api/admin/entries` только строчку: время, координаты, ключи файлов.

Так мы обходим лимит тела запроса Vercel (4.5 МБ) и не тратим ни секунды выполнения функции
на перекачку файлов.

**Порядок важен:** EXIF читается до пережатия, потому что canvas выбрасывает все метаданные.

### Сколько это займёт места

При ~3 записях в день: **~1100 фото и ~165 МБ в год**. Бесплатный R2 — 10 ГБ, то есть запас
примерно на 60 лет. В Neon лежат только строки: ~200 байт на запись, 0.2 МБ в год при лимите 0.5 ГБ.

## Установка

### 1. Neon (база)

1. Заведи проект на [neon.com](https://neon.com) (Free plan).
2. Скопируй **pooled** connection string.
3. Примени схему:

```bash
cp .env.example .env.local     # впиши DATABASE_URL
npm install
npm run db:init
```

Либо просто вставь содержимое `db/schema.sql` в SQL Editor в консоли Neon.

> Compute у Neon засыпает через 5 минут простоя и **просыпается сам** за пару сотен
> миллисекунд при следующем запросе. Руками будить ничего не надо.
> Только не вешай на базу крон или health-check — он будет держать её проснувшейся
> и сожрёт 100 CU-часов месячного лимита впустую.

### 2. Cloudflare R2 (фото)

1. Cloudflare → **R2** → Create bucket, назови `tisha`.
2. **Manage API tokens** → Create API token → права *Object Read & Write* на этот бакет.
3. Возьми Account ID (правая колонка на странице R2), Access Key ID и Secret.
4. Настрой CORS у бакета — иначе браузер не сможет грузить напрямую.
   Settings бакета → CORS policy:

```json
[
  {
    "AllowedOrigins": ["http://localhost:3000", "https://ТВОЙ-ДОМЕН.vercel.app"],
    "AllowedMethods": ["PUT", "GET"],
    "AllowedHeaders": ["content-type"],
    "MaxAgeSeconds": 3600
  }
]
```

Бакет остаётся **приватным**: фото отдаются по подписанным ссылкам на час. Если хочешь
отдавать их напрямую с CDN — подключи к бакету свой домен и пропиши `R2_PUBLIC_BASE_URL`.
Учти, что тогда фото становятся публично читаемыми для всех, кто знает URL.

### 3. Локальный запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000, нажми **вход**, введи `ADMIN_PASSWORD` из `.env.local`.

### 4. Деплой на Vercel

```bash
git push origin main
```

На Vercel: Import Project → выбери репозиторий → в **Environment Variables** скопируй все
переменные из `.env.local`. Не забудь потом добавить боевой домен в CORS-политику R2.

---

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `DATABASE_URL` | да | Pooled connection string из Neon |
| `R2_ACCOUNT_ID` | да | Account ID в Cloudflare |
| `R2_BUCKET` | да | Имя бакета |
| `R2_ACCESS_KEY_ID` | да | Из R2 API token |
| `R2_SECRET_ACCESS_KEY` | да | Из R2 API token |
| `R2_PUBLIC_BASE_URL` | нет | Публичный домен бакета. Пусто = приватный бакет + подписанные ссылки |
| `ADMIN_PASSWORD` | да | Пароль на загрузку. Смена разлогинивает все сессии |

## Если у фото нет координат

Это будет случаться, и это нормально. Причины:

- в настройках iPhone выключена передача геоданных при шаринге;
- фото прошло через мессенджер — метаданные вырезаны;
- Safari перекодировал файл при выборе (поэтому в `<input>` намеренно стоит только
  `accept="image/*"` — если добавить туда `image/heic`, Safari 17+ начинает конвертировать
  файлы на входе).

Такие фото приложение не выбрасывает: они попадают в список с пометкой «нет координат»,
жмёшь «поставить на карте» и кликаешь нужное место. Запись помечается как `manual`.

## Заметки

- Одинаковые фото не задваиваются: уникальный индекс по (время, координаты с точностью
  до ~1 м) молча отбрасывает повторный импорт.
- Метки группируются в кластеры (`leaflet.markercluster`), так что и на нескольких тысячах
  точек карта не тормозит.
- Клик по строке в списке подлетает к метке на карте.
- Тайлы OpenStreetMap бесплатны и не требуют ключа, но у них есть
  [политика использования](https://operations.osmfoundation.org/policies/tiles/) — для личного
  проекта с такими объёмами это не проблема.
