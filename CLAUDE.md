# CLAUDE.md — Карта Тиши

Контекст проекта для Claude Code. Держим его коротким и точным: что делает приложение,
какие фичи, на какой инфраструктуре и где что лежит.

## Что это

Веб-приложение «Карта Тиши». Пользователь закидывает фото → приложение читает GPS-координаты
из EXIF → ставит метку на карте. Карта и список записей публичные (может смотреть кто угодно),
а загрузка и удаление — под паролем администратора.

Задумано как личный трекер: куда ходили/что видели, привязанное к точке и времени съёмки.

## Ключевая идея архитектуры

**Фото никогда не проходят через сервер.** Всё пережатие и чтение метаданных происходит в
браузере, а файл грузится напрямую в объектное хранилище по подписанной ссылке. Это обходит
лимит тела запроса Vercel (4.5 МБ) и не тратит время выполнения serverless-функции на
перекачку картинок.

Клиентский пайплайн загрузки (`src/lib/upload.ts`, `src/lib/image.ts`):
1. Читает EXIF из **оригинала** (`exifr`; HEIC тоже, без конвертации).
2. Если файл HEIC — декодирует через `heic-to` (libheif в wasm, грузится лениво).
3. Ужимает до 1600px WebP + миниатюру 400px (~150 КБ и ~15 КБ).
4. Запрашивает у `/api/admin/upload-url` две подписанные PUT-ссылки и **грузит прямо в R2**.
5. Шлёт в `/api/admin/entries` только строку: время, координаты, ключи файлов.

**Порядок важен:** EXIF читается ДО пережатия — `canvas` выбрасывает все метаданные.

## Фичи

- **Карта** (Leaflet + OpenStreetMap, без API-ключа). Метки группируются в кластеры
  (`leaflet.markercluster`) — карта не тормозит на тысячах точек.
- **Список записей** — синхронизирован с картой, клик по строке подлетает к метке.
- **Загрузка из браузера** — мультизагрузка, превью, статусы (ready/uploading/error/duplicate).
- **Фото без координат** не выбрасываются: попадают в список с пометкой, дальше «поставить
  на карте» вручную → запись помечается `source = 'manual'`.
- **Дедуп**: уникальный индекс по (время, координаты ~1 м) молча отбрасывает повторный импорт
  того же фото.
- **Загрузка через Telegram-бота** (опционально) — обход бага Android 10+ (Scoped Storage
  режет GPS в системном пикере). Фото шлётся боту **как файл**, сервер сам его обрабатывает
  (`src/app/api/telegram/webhook/route.ts`, `src/lib/imageServer.ts` на `sharp`). Бот слушает
  только одного пользователя (по числовому Telegram ID), вебхук защищён secret-токеном.
- **Видео-скраб** (`src/components/VideoScrub.tsx`) — просмотр по кадрам.
- **Аналитика** (опционально) — Umami, скрипт грузится только если задан website ID.

## Инфраструктура

| Слой | Технология | Роль |
|---|---|---|
| Фронт/бэк | **Next.js 15** (App Router, React 19) | сайт + API-роуты |
| База | **Neon** (Serverless Postgres, `@neondatabase/serverless`) | строки записей (время, координаты, ключи, note) |
| Хранилище фото | **Cloudflare R2** (S3-совместимое, `aws4fetch`) | оригиналы + миниатюры, приватный бакет + подписанные ссылки |
| Хостинг | **Vercel** | деплой из git, переменные окружения |
| Карта | Leaflet + OpenStreetMap | тайлы бесплатные, без ключа |
| Загрузка (обход) | Telegram Bot API | приём фото как файла, серверный `sharp`-пайплайн |

Объёмы (при ~3 записях/день): ~1100 фото и ~165 МБ/год в R2 (лимит free 10 ГБ), в Neon —
~0.2 МБ/год (лимит 0.5 ГБ). Всё укладывается в бесплатные тарифы.

> Neon compute засыпает через 5 мин простоя и просыпается сам за ~сотни мс. **Не вешать на
> базу крон/health-check** — будет держать её проснувшейся и сожрёт месячный лимит CU-часов.

## Данные

Одна таблица `entries` (`db/schema.sql`): `id`, `taken_at`, `lat`, `lng`,
`source ('exif'|'manual')`, `photo_key`, `thumb_key`, `note`, `created_at`. Индексы по
времени, bbox и уникальный dedupe-индекс. Ключи файлов раскладываются по папкам
`photos/YYYY/MM/<uuid>.webp` (random uuid, чтобы публичный URL нельзя было угадать перебором дат).

## Аутентификация

Пароль один — `ADMIN_PASSWORD` (`src/lib/auth.ts`). В куку кладётся HMAC от фиксированной
строки на ключе-пароле, сам пароль в браузере не хранится. Смена `ADMIN_PASSWORD`
инвалидирует все сессии. Куки скоупятся по origin — залогинившись на `localhost`, на
`192.168.x.x` будешь разлогинен (частый источник 401).

## Переменные окружения

Полный список и как их получить — в `.env.example` и `README.md`. Обязательные: `DATABASE_URL`,
`R2_ACCOUNT_ID`, `R2_BUCKET`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `ADMIN_PASSWORD`.
Опциональные: `R2_PUBLIC_BASE_URL`, `TELEGRAM_*`, `NEXT_PUBLIC_UMAMI_WEBSITE_ID`.

## Подводные камни

- **EXIF читать до пережатия** — иначе canvas сотрёт метаданные.
- **HEIC от Telegram-бота** может не декодироваться, если серверная `sharp` собрана без HEIF
  — тогда бот отвечает «format not supported», такие фото грузить через сайт.
- **CORS у R2** обязателен: в политику бакета добавить `http://localhost:3000` и боевой
  `https://<домен>.vercel.app`, иначе браузер не сможет грузить напрямую.
- **Фото как «Фото» в Telegram** — Telegram пережмёт и сотрёт EXIF; слать только как «Файл».
